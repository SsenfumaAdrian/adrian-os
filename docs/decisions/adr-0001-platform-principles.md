# ADR 0001: Platform Principles

## Status
Accepted

## Decision
ADRIAN OS will be built as a first-principles operating system ecosystem with:
- Rust as the primary systems language
- Dart as the primary application/UI language
- Python restricted to tooling and AI workflows
- Hybrid modular kernel architecture
- Capability-based zero-trust security
- Native application ecosystem only

## Rationale
These choices maximize long-term maintainability, security, platform control, and product differentiation.
