# ADRIAN OS Entry Code Model v1

## Purpose
Document the first code-level entry model for the boot-image wrapper path.

## Current Model
- wrapper-side entry remains conceptual
- phase identity is explicit
- experiment start status is visible in code
- no true low-level boot symbol is implemented yet

## Role
This model completes the staged wrapper-side flow structure for FBE-1 planning and future boot artifact evolution.
