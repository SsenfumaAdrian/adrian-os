# ADRIAN OS Synthetic Handoff Code Model v1

## Purpose
Document the first code-level synthetic handoff object for FBE-1 wrapper-side flow.

## Current Role
- compile-clean
- wrapper-owned
- temporary
- experiment-oriented

## Included Concepts
- version
- architecture label
- experiment mode flag
- marker path intent flag
- status label

## Rule
This object is not a final boot contract and must not become a hidden replacement for BootContext.
